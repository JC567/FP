# 二、最重要原则：严禁未来函数

这是整个系统最重要的工程约束。

任何历史日期 t 的分析，只允许使用：

> **在日期 t 当时已经公开可获得的数据。**

禁止：

* 使用未来财报数据
* 使用未来年度分红数据
* 使用未来PE
* 使用后来修正后的财务数据
* 使用未来股价
* 使用未来计算出的TTM
* 使用今天的数据回填历史
* 使用后见之明判断历史信号

必须采用：

> Point-in-Time Data（时点数据）

例如：

2023-06-30进行估值分析：

只能使用2023-06-30之前已经公布的数据。

如果2023年中报于2023-08-30发布：

那么2023-06-30的模型不能使用该中报数据。

程序必须保存：

* report_period
* announcement_date
* effective_date

并以：

> announcement_date <= analysis_date

作为财务数据是否可用的核心判断条件。

# 四、一个非常重要的价格口径问题

不要简单地使用：

> 后复权价格 + 历史分红

计算历史股息率。

必须建立严格的经济学口径。

当前股息率：

```text
Dividend Yield_t =
TTM Dividend Per Share_t / Price_t
```

历史股息率：

```text
Dividend Yield_t =
Dividend available at t / Price available at t
```

必须确保分子中的分红是：

> 在 t 时点已经确定/可获得的近12个月现金分红。

不能使用未来分红。

如果数据源提供的是：

* 每股分红
* 除权除息日
* 股权登记日
* 公告日

优先按照公告可得性和实际支付口径建立TTM分红序列。

如果数据源口径无法完全确定：

必须在结果中标记：

> 数据口径风险

而不能假装数据精确。

# 五、PE计算

定义：

```text
PE_TTM = Price / EPS_TTM
```

其中：

```text
EPS_TTM = TTM Net Profit / Latest Diluted Shares
```

优先使用数据源直接提供的PE_TTM。

如果自行计算：

必须明确：

* 归母净利润TTM
* 总股本/稀释股本
* 股本变化
* 配股
* 增发
* 回购注销

对于：

```text
EPS <= 0
```

对应PE：

> 标记为无效PE，不直接参与正常PE分位计算。

# 六、PE历史分位数

默认：

> 10年历史窗口

同时计算：

> 5年历史窗口

定义：

```text
PE_Pct =
count(历史PE < 当前PE) / count(有效历史PE) × 100
```

例如：

当前PE = 10

过去10年有效PE样本：

1000个

其中900个PE高于10。

则：

```text
PE_Pct = 100 / 1000 = 10%
```

注意：

必须明确：

> “低于当前PE”的样本数

而不是使用Excel/Pandas默认percentile方法替代。

建议同时输出：

```text
PE_Pct
PE_Pct_5Y
PE_Min
PE_Max
PE_Median
PE_P10
PE_P25
PE_P50
PE_P75
PE_P90
```

# 七、PE异常值处理

必须提供配置项：

```python
PE_CONFIG = {
    "negative_pe": "exclude",
    "winsorize": False,
    "upper_bound": None
}
```

默认：

> PE <= 0排除。

对于极端高PE：

例如：

PE > 1000

不要直接删除。

应同时保存：

```text
raw_pe
valid_pe
pe_outlier_flag
```

并允许用户选择：

* exclude
* winsorize
* keep

默认使用：

> negative PE exclude，正PE全部保留。

原因：

估值系统不能人为删除“极端昂贵”的历史时期，否则会系统性美化当前估值。

# 八、股息率

定义：

```text
Dividend Yield =
TTM Cash Dividend Per Share / Current Price
```

必须计算：

```text
DY_Pct_10Y
DY_Pct_5Y
DY_Current
DY_Min
DY_Max
DY_Median
DY_P10
DY_P25
DY_P50
DY_P75
DY_P90
```

历史排名：

```text
DY_Pct =
count(Historical DY < Current DY) / valid_samples
```

注意：

股息率越高越便宜。

因此：

> DY_Pct越高 → 越有利。

# 九、分红率

定义：

```text
Payout Ratio =
TTM Cash Dividend / TTM Net Profit
```

即：

```text
PR =
Cash Dividend Total / Attributable Net Profit TTM
```

注意：

分红率与股息率完全不同。

股息率：

> 市场价格维度

分红率：

> 公司利润分配政策维度

必须分别计算。

# 十五、Gordon Growth Model

使用Dividend Discount Model：

```text
P = D1 / (Ke - g)
```

对于稳定增长公司：

```text
P/E = Payout Ratio / (Ke - g)
```

即：

```text
Fair PE =
Payout Ratio / (Required Return - Growth Rate)
```

其中：

```text
Required Return =
Risk Free Rate + Equity Risk Premium
```

默认：

```text
ERP = 5%
```

但必须允许配置。

---

# 十六、长期增长率估计

不要直接拍脑袋。

建立：

```text
g = min(
    historical_earnings_growth,
    sustainable_growth,
    industry_growth,
    nominal_GDP_growth
)
```

但实际工程中必须加入合理约束。

例如：

```text
g <= Ke - 2%
```

避免：

```text
g >= Ke
```

导致Gordon模型失效。

如果：

```text
g >= Ke
```

必须：

> 标记GGM_INVALID

不能输出虚假的合理PE。

# 五十、最终原则

这个系统不是：

> “预测股票未来涨多少”。

而是：

> **判断当前股票价格相对于自身历史、盈利能力、分红能力、无风险利率以及内在价值，处于什么位置。**

因此最终输出必须区分：

```text
便宜 ≠ 一定上涨
高股息 ≠ 一定安全
低PE ≠ 一定低估
高分红 ≠ 一定可持续
历史低估 ≠ 未来不会继续下跌
```

系统最终需要回答的是：

> **“现在这个价格，是否值得承担这个公司的风险？”**

而不是：

> **“这只股票会不会上涨？”**
